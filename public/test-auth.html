📖 Common Issues

"Unexpected token '<'" - Click to expand

This means the server returned HTML instead of JSON. Usually happens when:

  • Windows Authentication is triggering a 401 challenge
  • IIS is returning an error page
  • The endpoint doesn't exist (404 page)

Fix: Check if Windows Authentication is enabled in IIS, and use hostname instead of IP.

Persistent popup asking for credentials - Click to expand

Windows Authentication is challenging every request but not accepting credentials.

  • Ensure you're using http://hosppdevsrv:3333 (hostname)
  • Add site to browser's Intranet zone
  • Ensure computer is domain-joined
  • Check that user account is in ifl.net domain
CORS errors in console - Click to expand

Usually not the problem for same-origin requests. If you see CORS errors:

  • Check that you're accessing the same hostname/port
  • Don't mix http and https
  • Check IIS CORS settings if needed

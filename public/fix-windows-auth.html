Step 2: Manual Intranet Zone Setup

If the test above fails, your browser is NOT in Intranet zone. Follow these steps:

For Chrome/Edge:

  1. Open Control Panel → Internet Options
  2. Go to Security tab
  3. Click Local intranet → Sites → Advanced
  4. Add these URLs (one at a time):
    http://hosppdevsrv:3333
    http://hosppdevsrv.ifl.net:3333
  5. Click Close → OK → OK
  6. IMPORTANT: Close ALL browser windows completely
  7. Open a new browser window
  8. Come back to this page and run Step 1 test again
⚠️ CRITICAL: You MUST use the hostname (hosppdevsrv:3333) in the address bar, NOT the IP address!

Step 3: Verify Domain Login

Windows Authentication only works if you're logged in with a domain account.

How to check manually:

  1. Open Command Prompt
  2. Type: whoami and press Enter
  3. You should see: IBRAHIM1_NT\ISRARULHAQ or similar
  4. If you see just ISRARULHAQ (no domain), you're NOT logged in with domain account

Step 4: Registry Quick Fix (Advanced)

If manual Internet Options doesn't work, try adding registry entries directly:

Run these commands in PowerShell (Run as Administrator):

# Add hosppdevsrv to Intranet zone
New-Item -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings\ZoneMap\Domains\hosppdevsrv" -Force
New-ItemProperty -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings\ZoneMap\Domains\hosppdevsrv" -Name "http" -Value 1 -PropertyType DWord -Force

# Verify it was added
Get-ItemProperty -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings\ZoneMap\Domains\hosppdevsrv"

After running these commands:

  1. Close ALL browser windows
  2. Restart browser
  3. Test again
